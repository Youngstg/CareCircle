## Integration notes

- `src/app/page.tsx` uses the three photographs for the hero, responsibilities feature, and privacy section. `src/app/(auth)/layout.tsx` reuses the connection photograph beside sign-in/sign-up forms.
- Use the dimensions above to reserve layout space. Preserve the supplied aspect ratios where practical; the portrait already has a close crop, so avoid cropping away faces or joined hands.
- Keep text beside the photographs rather than over faces. Use descriptive alt text when an image adds meaning, or empty alt text when it is purely decorative and the adjacent content already conveys the same meaning.
- Prioritize only the image actually visible above the fold; defer offscreen supporting images. Serving the local files avoids runtime requests to the stock provider.
